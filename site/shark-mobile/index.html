① 웹 앱으로 쓰기

  1. 맥의 Shark 에서 설정 → 원격 Shark 서버 → 이 Shark 서버 공유로 가요.
  2. 다른 기기를 고르고, 주소에 맥의 와이파이 주소(보통 192.168. 로 시작)를 고른 뒤 링크 만들기를 눌러요.
  3. 나온 브라우저 링크를 아이패드로 보내요. 같은 애플 계정이면 맥에서 복사해 아이패드에서 바로 붙여 넣을 수 있어요.
  4. 아이패드 Safari 에서 링크를 열면 Shark 가 떠요.
  5. Safari 의 공유 단추 → 홈 화면에 추가를 누르면 남색 Shark 아이콘이 생겨요.
  6. 홈 화면의 Shark 를 처음 켜면 연결 링크를 묻는 칸이 나올 수 있어요. 3번의 링크를 한 번 더 붙여 넣으면 돼요.

맥을 껐다 켜서 와이파이 주소가 바뀌면 1~3번으로 새 링크를 만들어요.

② 모바일 앱으로 깔기

Xcode 에 애플 계정을 넣고(Xcode → Settings → Accounts), 기기에서 설정 → 개인정보 보호 및 보안 → 개발자 모드를 켠 뒤 케이블로 맥에 연결해요. 그다음 Shark 저장소에서 이렇게 해요. 

cd mobile
pnpm install
npx expo prebuild --platform ios
open ios/Shark.xcworkspace
  1. Shark 타깃 → Signing & Capabilities 에서 Team 에 내 계정을 고르고, Bundle Identifier 를 나만의 이름(예: com.내이름.shark)으로 바꿔요.
  2. 무료 계정이면 같은 화면의 Push Notifications 를 지워요. 무료 계정은 이 기능을 쓸 수 없어요.
  3. 위쪽에서 내 기기를 고르고 ▶ 를 눌러요.
  4. 기기의 설정 → 일반 → VPN 및 기기 관리에서 내 계정을 신뢰하고 앱을 켜요.
  5. 앱에서 연결 단추를 누르고, 맥의 Shark 설정 → 모바일에 뜬 QR 코드를 비추면 연결돼요.

무료 계정으로 깐 앱은 7일 뒤에 안 켜져요. 그러면 기기를 다시 연결하고 ▶ 를 한 번 더 누르면 돼요.
